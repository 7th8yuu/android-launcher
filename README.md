# My Launcher

Launcher Android (Kotlin + Jetpack Compose + Material 3) với giao diện "Liquid Glass".

- Nhiều trang màn hình chính, widget, dock
- Thư viện ứng dụng kiểu App Library (Trò chơi / Mạng xã hội / Giải trí / Tiện ích / Khác) + A–Z + tìm kiếm
- Bộ biểu tượng (ADW/Nova/Go) hoặc ảnh tự chọn cho từng ứng dụng
- Chạm 2 lần để khoá màn hình (dịch vụ trợ năng), cài đặt trong app
- Animation: vuốt lên theo ngón tay, mở/đóng ứng dụng, chuyển trang 3D, nhấn lò xo

Build: GitHub Actions (`.github/workflows/build.yml`) → artifact `MyLauncher-debug-apk`.
